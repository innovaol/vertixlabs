# Vertix Labs — Official Corporate Website & Brand Identity

The official corporate web presence, legal repository, and brand identity for **Vertix Labs LLC** (`vertixlabs.dev`), an independent software engineering studio specializing in high-performance mobile applications and productivity tools.

## Brand Identity & Design System

- **Official Mark:** *The Symmetrical Aerodynamic Vertex* — A mathematical, bilateral emblem composed of twin titanium-cobalt blades meeting at an emerald floating anchor node.
- **Brand Assets:**
  - `assets/icon.svg`: Vector mark (App icons, squircle, avatar)
  - `assets/logo.svg`: Complete corporate horizontal lockup
  - `assets/favicon.svg`: Scalable high-contrast browser favicon

## Architecture & Deployment

- **Stack:** Pure semantic HTML5 + Tailwind CSS + Lucide Icons
- **Deployment:** Cloudflare Pages (Global Anycast Edge Network)
- **Domain:** [https://vertixlabs.dev](https://vertixlabs.dev)

## Key Sections

- **Landing Page:** Presentation of Vertix Labs LLC and software studio philosophy.
- **Featured Product:** Showcasing **QuoteFast** (Instant quote & invoice mobile generator).
- **Compliance & Registry:** Formal business disclosure (Wyoming LLC, Sheridan, WY).
- **Developer Stores:** Apple Developer Program & Google Play Console organization verification.
- **Legal Policies:**
  - `privacy.html`: Comprehensive Mobile App & Web Privacy Policy.
  - `terms.html`: Formal Terms of Service (Wyoming jurisdiction).
